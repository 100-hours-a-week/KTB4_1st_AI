## 1. 서비스 개요

* 바꾸까는 지역/목적 기반 그룹에 참여한 사용자가 그룹 안에서 물건을 등록하고, 다른 사용자의 물건과 교환을 요청하며 채팅으로 조율하는 물물교환 서비스다
* v1·v2는 일반 웹, v3부터는 PWA(설치 가능한 웹앱)로 제공한다
* 사용자 역할은 단일하다. 등급·관리자 회원 구분이 없고, 모든 사용자가 물건 등록·조회·교환 요청을 동일하게 할 수 있다

---

## 2. 계정 정책

* 로그인은 카카오 로그인만 지원한다
* 인증 성공 시 세션 저장 → 기존 사용자는 물건 리스트로, 신규 사용자는 거래 취향 설정으로 이동한다
* 인증 중 로딩·중복 요청은 차단되고, 취소/실패/콜백 오류 시 시작 화면을 유지하며 재시도할 수 있다
* 거래 취향 설정
    * 로그인 직후 최초 1회만 진행(완료자는 건너뜀)
    * 거래 3문항 + 대화 4문항 + 진행 2문항, 총 9문항 모두 응답해야 완료
    * 저장값은 매칭·채팅 톤 추천에 사용
    * 미완료 상태에서 뒤로가기 시 로그아웃 여부 확인
* 회원 탈퇴
    * 마이페이지 > 탈퇴 절차, 확인 모달 경유
    * 탈퇴 7일 후 전체 데이터 삭제
    * 카카오 계정 정보 보관 기간은 미정
    * 탈퇴 시점 제재 이력이 있는 계정의 재가입 제한은 9.4 참고
* 계정 비활성화/제재: 9장 참고

## 3. 그룹 정책

### 3.1 그룹 생성

* 그룹명: 필수, 30자 이내, 중복 불가
* 설명: 선택, 300자 이내
* 위치: 필수
    * v1: 주소 검색으로 위치 선택
    * v2부터: 기기 현재 위치 권한 허용 + 위치 조회 성공이 모두 있어야 생성 가능. 권한 거부·조회 실패·미조회 시 생성 차단
* 참여 중인 그룹이 5개면 생성 제한(3.4의 참여 그룹 5개 제한과 동일 규칙)

### 3.2 그룹 검색

* 그룹명 완전 일치 방식(부분 일치·초성 검색·오타 보정·유사어 검색 미제공)
* 검색어 앞뒤 공백 정리, 빈 검색어 실행 불가, 최대 50자
* 결과 없음 시 전용 안내 + 그룹 생성 유도
* 여러 요청이 겹쳐도 가장 최근 요청 결과만 반영

### 3.3 그룹 참가 — 위치 인증 (v3 전용)

* 위치 인증 기능은 v3에서 처음 도입된다. v1·v2는 위치 인증이 없고, 사용자 위치도 수집하지 않는다
* 관리자 승인이 아니라 "그룹 위치 근방에 있음"을 인증하는 방식으로 참가한다
* 세부 기준:
    * 인증 시점 사용자 위치 ↔ 그룹 기준 위치 거리 500m 이내(그룹 추천의 "가입 가능 범위"와 동일 기준, 3.6 참고)
    * 기기 위치 정확도 100m 이하인 경우에만 인증 인정
    * 인증 요청 시 새로 수집한 위치만 사용, 수집 후 5분 지난 위치는 사용 불가
    * 이전 인증 위치·백그라운드 위치 기록·마지막 확인 위치 등 과거 데이터는 사용 불가
    * 위치 권한 없음/기준 미충족 시 재측정 안내
    * 인증 완료 후 원본 좌표는 저장하지 않고, 인증 결과·인증 시각만 보관

### 3.4 그룹 목록/조회

* 참여 가능한 그룹 개수는 v1·v2·v3 공통으로 5개 제한이다
* v2부터 그룹 관리 화면의 목록 조회 자체는 첫 페이지 20개, 이후 10개씩 페이지네이션된다 — 이건 검색 결과·그룹 추천처럼 참여 여부와 무관하게 5개보다 많이 노출될 수 있는 목록을 위한 것이지, 참여 그룹 개수 제한과는 별개다
* 물건 리스트 화면의 그룹 드롭다운 "5개" 표기도 참여 그룹 5개 제한과 같은 값이다
* 그룹 상세는 한 번에 하나만 펼칠 수 있다
* 진행 중인 교환이 있으면 탈퇴 제한(3.5 참고)

### 3.5 그룹 탈퇴

* 진행 중인 교환 요청(받은/보낸 무관)이 있으면 탈퇴 불가. 아직 수락되지 않은 요청은 "진행 중"이 아니므로 탈퇴 가능
* 그룹에 한 명만 남은 상태에서 탈퇴하면 그룹이 삭제된다

### 3.6 그룹 추천 기준

* v1·v2: 위치 미수집. 가입자 많은 순 → 가나다 순
* v3: 사용자 현재 위치 기반, 가입 가능 범위 500m 이내인 그룹 중 가입자 많은 순으로 노출. 이 500m은 3.3의 참가 위치 인증 반경과 동일한 기준이다

## 4. 물건(상품) 정책

### 4.1 등록/수정

* 사진 최소 1장, 최대 3장
* 제목 100자, 내용 2,000자, 수량 1 이상의 정수
* 노출 그룹 1~5개 선택
* 등록 가능 개수는 총 99개까지("99개 초과로 입력 하실 수 없습니다" 안내)
* 업로드/요청 중 중복 제출 차단, 실패 시 입력값·미리보기 유지
* "거래 가능" 상태일 때만 수정 가능, "거래 완료" 상태는 수정 버튼 비활성화

### 4.2 물건 상태

* 재고 1개 이상 = 교환 가능, 재고 0개 = 교환 완료

### 4.3 물건 상세

* 구매자: 조회 + 교환 제안만 가능
* 판매자(등록자): 본인 물건 수정 가능
* 거래 완료 시 제안 버튼 비활성화
* v2부터 조회수·관심 수·제안 횟수 노출
* v3부터 신고 기능 추가(9장 참고)

### 4.4 물건 검색

* 물건명 완전 일치 방식(부분 일치·초성 검색·오타 보정·유사어 검색 미제공)
* 물건 리스트 검색 아이콘 진입, 최근 검색어 상위 10개 관리·개별 삭제
* 검색 중 로딩·결과 없음·실패 구분
* 스마트 검색(자연어/AI 기반, 조건 검색)은 완전 일치 검색과는 별도 정책이 공존하는 것이며 서로 충돌하는 게 아니다. 스마트 검색 상세는 7장 참고

### 4.5 관심(찜)

* v2부터 지원. 목록/상세 카드에서 토글, 관심 수·제안 수 노출, 마이페이지에서 별도 조회

## 5. 교환 정책

### 5.1 요청 흐름

* 교환 대상 물건 확인 후, 자신이 낼 물건·수량을 1개 이상 선택해 요청
* 보유 수량 초과 불가, 미선택 시 요청 불가, 전송 중 중복 요청 차단
* 요청 시 자동으로 해당 교환 전용 채팅방이 생성된다
* AI 조합 추천·가치 비율 판정(v2)은 7장 AI 정책에서 다룬다

### 5.2 교환 거래 상태

* "교환 요청"과 "진행 중"은 별도 상태로 구분하지 않는다
* 정의된 상태는 요청 단위 "교환 완료"/"교환 거절"과 물건 단위 "거래 완료"/"거래 가능" 뿐이다

### 5.3 완료/거절 처리

* 제안을 받은 쪽(판매자)이 단독으로 완료를 확정 → 완료 시 재고 차감
* 거절 시 거절 결과 반영. 처리 중 중복 처리 차단

### 5.4 교환 요청 수정/취소

* 구매자가 채팅방의 교환 정보 카드를 펼치면 "교환 수정"/"교환 취소" 버튼을 제공한다 — v1부터 제공
* 수정 시 "(시스템) 교환 정보가 변경되었습니다" 시스템 메시지가 채팅방에 남는다

---

## 6. 채팅 정책

### 6.1 채팅 목록

* 전체 / 받은 교환 / 보낸 교환 탭
* 안읽음 우선 + 최신순 정렬
* 나가기 확인 모달("채팅방을 나가시겠습니까?"), 실패 시 목록 복구

### 6.2 채팅방 내 액션

* 구매자: 상대 물건·요청 카드·메시지 확인, 본인이 보낸 요청 수정/취소(5.4 참고), 시스템 메시지 자체는 액션 없음
* 판매자: 요청 상세 조회, 완료/거절 처리(거래 가능 상태에서 완료·거절 버튼 가로 배치), 메시지 전송

### 6.3 나가기/재입장

* 진행 중인 요청이 있으면 나갈 수 없다
* 나가면 재입장 없이 즉시 삭제된다
* 나가지 않은 채팅방은 언제든 재입장해 대화 내역을 볼 수 있다

---

## 7. AI/스마트 검색 정책

* 자연어 AI 도우미(v2)
    * 자연어로 물건 검색, 화면 안내, 정책/기능 문의, 교환 가능 물건 추천 요청
    * 빈 입력 전송 불가, 처리 중 로딩+전송 잠금, 결과 없음/실패 구분 안내
    * 창을 닫아도 같은 탭의 대화는 유지
* 스마트 검색(v2)
    * 거래 가능한 보유 물건을 다중 선택 + 원하는 교환 조건을 자유 텍스트로 최대 200자 입력
    * 최소 1개 선택해야 검색 활성화, 조회 중 중복 클릭 차단
    * 4.4의 물건 완전 일치 검색과는 별개 정책으로 공존한다
* 교환 AI 조합 추천·가치 비율 판정(v2, 교환 요청 화면에 적용)
    * 보유 물건 중 AI가 가치가 가까운 조합을 추천
    * 다중 물건·수량 선택 가능
    * 비율 90~110%를 적정으로 판정(미만=부족, 초과=초과), 부족 시 가능한 최대 조합을 안내

## 8. 마이페이지 정책

* v2부터 마이페이지 제공: 프로필(카카오 프로필, 조회 전용) + 등록 상품/완료 교환/그룹 관리/관심 상품 4개 활동 모드, 회원 탈퇴 메뉴
* v3부터 1:1 문의, 제재 내역 메뉴 추가

---

## 9. 신고 및 제재 정책

### 9.1 신고 접수/집계

* 구매자가 물건 상세에서 신고를 확정하면 게시글 등록자를 대상으로 접수
* 동일 대상 신고 건수는 최근 7일 기준 산정
* 동일 인물의 중복 접수는 시스템상 1건으로 합산(마지막 신고 기준 일시 갱신)
* 게시글/채팅 어느 경로든 하나의 사용자 신고 누적으로 통합

### 9.2 처리 절차

* 신고 접수 → 임시 조치(계정 활동 제한, 최대 48시간) → 관리자 검토(신고 사유·채팅 로그·사진 대조) → 확정 제재
* 혐의 입증 시 기본 경고 1회 + 3일 이용 정지
* 최근 100일 내 누적 경고 2회 시 30일 이용 정지
* 중대 사유(서비스 관리자 판단하에 법적으로 문제 될 수 있는 행위 — 명확한 사기, 특정 유저 대상 과한 비방 등)는 영구 제재
* 오신고 확인 시 즉시 임시 조치 해제·정상화
* 물건 상세의 "사용자 신고" 카드에는 "누적 3회 신고 시 계정 비활성화"라는 표현도 별도로 있다.

### 9.3 이의 제기

* 제재 후 7일 이내 마이페이지 > 1:1 문의로 접수
* 명백한 허위 신고(구체적 근거·자료) 또는 시스템 오류 시 복구
* 복구 시 경고 누적 차감 + 이용 권한 복원 + 오신고자에게 경고 1회 페널티
* 제재 내역 화면에 제재 기간(예: 30일간)과 이의 제기 안내가 함께 노출

### 9.4 탈퇴 계정의 신고 처리

* 탈퇴 시점 누적 신고·중대 사유 제재 대상이었던 사용자가 동일 정보로 재가입 시 제재일로부터 30일 이용 정지
* 중대 사유 영구 제재 대상자는 블랙리스트 DB 등재 → 데이터 보존 + 재가입 차단

## 10. 문의(1:1) 정책

* 마이페이지 > 1:1 문의에서 접수
* "48시간 이내로 답변 드리기 위해 노력 중" 안내 문구 확인.

---

## 11. 시간 표기 정책

* KST(UTC+09:00) 기준 상대 시간만 표기, `yyyy-mm-dd` 등 절대 날짜 미사용
* 구간별 기준:
    * 1분 미만: `방금`
    * 1분 이상 1시간 미만: `N분 전`
    * 1시간 이상 24시간 미만: `N시간 전`
    * 24시간 이상 365일 미만: `N일 전`
    * 365일 이상: `N년 전`
    * 수치는 해당 단위를 넘지 않는 범위에서 내림 처리

## 12. 버전 로드맵 및 배포 정책
